# Weather Forecasting System

A simple web application that provides weather information and forecasts for any city.

## Features

- Current weather conditions (temperature, humidity, wind speed)
- 5-day weather forecast
- Clean and responsive user interface
- Real-time weather updates using OpenWeatherMap API

## Setup Instructions

1. Install the required packages:
   ```
   pip install -r requirements.txt
   ```

2. Open `app.py` and replace `YOUR_API_KEY_HERE` with your OpenWeatherMap API key

3. Run the application:
   ```
   python app.py
   ```

4. Open your web browser and go to `http://localhost:5000`

## How to Use

1. Enter a city name in the search box
2. Click the "Search" button or press Enter
3. View current weather conditions and 5-day forecast

## Technology Stack

- Frontend: HTML, CSS (Bootstrap 5), JavaScript
- Backend: Python (Flask)
- API: OpenWeatherMap

## Note

To get an API key, sign up at [OpenWeatherMap](https://openweathermap.org/api) and generate a free API key.
